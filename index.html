Features

Generation + guarantee

Not just "AI draws a screen" — machine-context-driven generation with validated bindings, control authority and change continuity.

✦

Intent → validated HMI

Natural-language intent compiles to a screen whose every widget binds to a real, typed signal. Unresolved requests show UNKNOWN — never invented.

◉

PLC-authoritative control

Commands follow defined contracts and permissive checks. START is rejected when a permissive is false — the HMI can't bypass the PLC.

⇄

Change-aware continuity

Change a signal range and CANON traces impact across scaling, alarms, trends, tests & docs, then regenerates and re-validates.

⬡

Engineering graph

An interactive 3D traceability graph links requirement → asset → I/O → PLC → HMI → alarm → test → doc, and drives the impact engine.

🛢

Live 3D process twin

A real WebGL twin of TK-401 — tank, pump, valve, pipes — bound to live values, rotatable, and quality-aware (LIVE / STALE / UNKNOWN).

▤

Real recorded data

The runtime replays a real industrial testbed dataset (SKAB, Skoltech) — real pressure, flow, temperature and labelled anomalies drive the HMI.
