Normalization rules

Every extracted fact becomes:

{
  "factId": "fct_m262_opcua_server",
  "statement": "Modicon M262 exposes a configurable OPC UA server in EcoStruxure Machine Expert.",
  "status": "VERIFIED",
  "product": "Modicon M262",
  "sourceId": "src_m262_opcua_help",
  "url": "https://product-help.schneider-electric.com/...",
  "accessed": "2026-09-10",
  "layer": "A"
}

Contradictions (two docs disagree) keep both facts and set conflictGroup. Retriever must return conflicts; LLM must not pick a winner silently.

PacDrive / Lexium motion CAM tables



Safety PLC SIL application libraries



Entire Harmony symbol packs
