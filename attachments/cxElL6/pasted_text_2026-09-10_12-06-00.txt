2. PRODUCT
============================================================

PRODUCT NAME:

CANON

FULL TITLE:

CANON — Machine Context → Dynamic HMI → Verified Control

OPTIONAL SUBTITLE:

Engineering Context → Dynamic HMI → Verified Machine Interaction

CORE PRODUCT IDEA:

CANON creates a unified machine context from engineering information such as PLC/controller tags, I/O, asset hierarchy, alarms, communication configuration and machine documentation.

It converts that context into a canonical machine model.

Natural-language intent is interpreted against that actual machine context.

CANON then dynamically composes a machine-specific HMI using validated signals, commands and reusable industrial UI primitives.

The operator can visualize the machine and interact with defined controls through a PLC-authoritative command path.

When the engineering context changes, CANON identifies affected HMI dependencies and can regenerate/revalidate the affected interface.

THE CENTRAL MESSAGE:

“We don't generate a screen from a prompt. We generate a validated interface from the machine — and keep it in sync as the machine changes.”
