CANON — CANONICAL MACHINE MODEL
SCREEN 03 — MACHINE MODEL
MASTER UI GENERATION PROMPT
============================================================

CORE DIRECTIVE
============================================================

Design the third screen of CANON after:

PROJECT HUB
→ MACHINE CONTEXT
→ MACHINE MODEL

The engineer has already connected TK-401 and CANON has discovered
its engineering context.

Now show the engineer the most important transformation:

DISCOVERED MACHINE DATA
        ↓
CANONICAL MACHINE MODEL

The screen must communicate:

"CANON has turned the machine's engineering reality into a
structured, connected model that can safely drive everything
that comes next."

This is one of the HERO SCREENS of the entire product.

It must feel like premium industrial engineering software.

NOT a generic dashboard.
NOT a database browser.
NOT a chatbot.
NOT a mind map.
NOT a futuristic AI visualization.

============================================================
18. VISUAL STYLE
============================================================

Use:

- white / light neutral workspace
- graphite typography
- thin engineering lines
- subtle gray borders
- restrained green status indicators
- amber only for unresolved information
- red only for faults
- precise grid
- minimal shadows
- subtle radius
- excellent whitespace
- highly disciplined alignment

No gradients.

No neon.

No glassmorphism.

No excessive rounded cards.

No glowing nodes.

No decorative effects.
