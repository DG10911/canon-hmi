CANON — SCHNEIDER ELECTRIC INDUSTRIAL ENGINEERING PLATFORM
OPENING SCREEN / PROJECT HUB
MASTER UI GENERATION PROMPT — PREMIUM ENTERPRISE INDUSTRIAL SOFTWARE

============================================================
0. CORE DIRECTIVE
============================================================

Design the FIRST SCREEN of CANON as if Schneider Electric itself
were launching CANON as a serious next-generation industrial
engineering application.

This is NOT a marketing landing page.

This is NOT a generic SaaS dashboard.

This is NOT a ChatGPT interface.

This is NOT a colorful AI startup.

This is the actual opening workspace an industrial automation
engineer would see after launching the application.

The first impression must communicate:

ENGINEERING
INDUSTRIAL AUTOMATION
MACHINE CONNECTIVITY
TRUST
PRECISION
CONTINUITY
PROFESSIONAL SOFTWARE
SCHNEIDER-QUALITY PRODUCT DESIGN

The product should feel credible enough that a Schneider Electric
engineer could imagine this becoming a future engineering layer
around the EcoStruxure ecosystem.

============================================================
1. PRODUCT IDENTITY
============================================================

Product name:

CANON

Subtitle:

ENGINEERING INTELLIGENCE PLATFORM

Core philosophy:

ENGINEERING INTENT → VERIFIED AUTOMATION

Primary narrative:

Connect machines.
Understand machine context.
Build a canonical machine model.
Generate validated operator experiences.
Maintain engineering continuity as machines change.

The opening screen should immediately communicate that CANON
manages REAL ENGINEERING PROJECTS.

============================================================
2. VISUAL LANGUAGE
============================================================

Create a premium Schneider-inspired industrial software aesthetic.

Use:

- clean white / very light neutral workspace
- graphite / near-black typography
- subtle Schneider-inspired green accents
- restrained gray borders
- extremely clean spacing
- precise alignment
- technical typography
- compact enterprise controls
- thin dividers
- subtle status indicators
- minimal shadows
- restrained corner radius
- high information density without visual clutter

Use green ONLY for:

- healthy
- connected
- running
- successful
- primary confirmation

Use amber for:

- warning
- attention

Use red only for:

- fault
- disconnected
- critical condition

Do NOT use:

- gradients
- neon
- glassmorphism
- excessive rounded cards
- giant floating cards
- colorful backgrounds
- glowing effects
- AI robot graphics
- decorative 3D objects
- futuristic cyberpunk styling
- excessive animations
- generic startup illustrations

The interface must feel engineered rather than decorated.

============================================================
3. FIRST IMPRESSION
============================================================

When the application opens, the engineer should immediately think:

"I am inside a serious industrial engineering environment."

NOT:

"I am inside an AI chatbot."

NOT:

"This is a marketing website."

The screen should resemble the quality and seriousness of a
professional industrial engineering workstation.

============================================================
17. TYPOGRAPHY
============================================================

Typography must be highly disciplined.

Use:

- strong technical page titles
- compact uppercase section labels
- highly readable body text
- tabular-looking numeric values
- restrained font weights

Hierarchy:

CANON
↓
ENGINEERING PROJECTS
↓
PROJECT NAME
↓
Machine metadata
↓
Status / engineering counts

Avoid oversized typography.

============================================================
18. GRID AND ALIGNMENT
============================================================

Everything must align to a strict engineering grid.

Use:

- consistent left edge
- consistent horizontal spacing
- consistent row heights
- aligned numerical columns
- aligned status indicators
- generous whitespace around major sections
- dense but readable project information

No randomly floating elements.

No asymmetrical decorative layouts.

============================================================
19. MOTION
============================================================

Use only subtle professional motion.

On application launch:

1. CANON shell appears
2. system status initializes
3. project data resolves
4. running indicators become active

Very subtle.

No cinematic startup animation.

No particle effects.

No zooming camera.

No flashy transitions.

The software should feel fast.
