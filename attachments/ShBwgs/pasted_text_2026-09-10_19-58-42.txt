============================================================
CORE DIRECTIVE
============================================================

Design the second screen of CANON immediately after the engineer
opens an existing project from the Project Hub.

The engineer has selected:

TK-401
PROCESS TANK

This screen must communicate one fundamental idea:

CANON IS FIRST UNDERSTANDING THE MACHINE BEFORE IT GENERATES
ANYTHING.

This is NOT a generic data dashboard.
This is NOT an analytics screen.
This is NOT a chatbot.
This is NOT a giant asset browser.

It is a premium industrial engineering "machine discovery"
workspace.

The visual quality should feel comparable to serious industrial
automation engineering software.

============================================================
15. DESIGN LANGUAGE
============================================================

Use the same design system as the Project Hub:

White / light neutral background.

Graphite typography.

Thin gray dividers.

Subtle green for healthy/verified states.

Amber for unresolved information.

Red only for actual faults.

Precise spacing.

Minimal rounded corners.

No gradients.

No glassmorphism.

No neon.

No excessive shadows.

No decorative illustrations.
