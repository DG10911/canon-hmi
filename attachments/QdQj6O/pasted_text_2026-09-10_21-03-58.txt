P0 plant model (PROPOSED)

Assets: TK-401, P401, XV401
Signals: LT401, PT401, P401_RUNNING, P401_FAULT, P401_START_REQ, P401_STOP_REQ, XV401_OPEN, XV401_CLOSED, XV401_OPEN_REQ, XV401_CLOSE_REQ

Discrete-time tick dt = 0.2 s.

if P401_RUNNING and XV401_OPEN:
    level += inflow_rate * dt
    pressure = f(level, pump_curve)
else:
    level += leak_or_hold
    pressure decays toward atmospheric_head(level)

if level >= LT401_HIGH: HIGH_ALARM
if pressure >= PT401_HIGH: PRESSURE_ALARM
if P401_START_REQ:
    if XV401_OPEN and level < LT401_HIGH and not P401_FAULT:
        P401_RUNNING = true
        P401_START_REQ clears after ack
    else:
        reject (reason code)
if XV401_CLOSE_REQ:
    XV401_OPEN = false
    if P401_RUNNING: optional interlock trip (configurable)

Seed + tick count → bit-identical traces. Record traces as regression fixtures.

Command timeout: if START_REQ asserted and RUNNING not true within 5 s → CMD_TIMEOUT alarm.
