08 — CANON API and Protocol Evaluation



A. Machine connectivity protocols

OPC UA (IEC 62541) — PRIMARY industrial protocol







Field



Assessment





Purpose



Secure, modeled, subscribed access to controller variables





CANON use



Browse (optional), read, write command request nodes, subscribe to values/alarms





Schneider relevance



VERIFIED: Server Expert; M580 BMENUA0100; M262 embedded server; Machine Expert OpcUaHandling client FBs





Real-time suitability



Subscriptions adequate for HMI (100–1000 ms). Not motion-cycle real time.





Security



Certificates, policies, user tokens. Anonymous exists on some SE defaults — disable in any non-demo.





Browser compatibility



Do not run OPC UA in the browser.





Docker



Yes for open stacks

PRIMARY: asyncua
BACKUP: node-opcua
WHY: Backend is FastAPI. One library implements both the CANON client and the demo OPC UA server. Subscriptions, browse, read/write, timestamps, and basic security are sufficient. node-opcua is the escape hatch if a TypeScript sidecar is added. open62541 is overkill for PS2.

Test client (human): UaExpert (Unified Automation freeware). Not licensed for embedding.

Simulators: asyncua Server() with a frozen address space matching canon_demo_signals.json. Public demo endpoints (Sterfive, Prosys) are useful for client bring-up but must not be the graded demo.

NodeSets: Optional P2. Demo server uses a custom namespace urn:canon:demo:tk401. Do not claim Schneider companion-spec compliance.

Modbus TCP — PRIMARY fallback / simple I/O







Field



Assessment





Purpose



Register/coil access to PLCs and drives





CANON use



Read holding/input registers; write request coils; decode INT16/UINT16/FLOAT32 (byte order documented)





Schneider relevance



VERIFIED: OPC UA Server Expert speaks Modbus/TCP to devices; Modicon Ethernet CPUs historically expose Modbus/TCP. Do not claim a specific CPU SKU without its datasheet.





Modbus RTU



P2 (serial). Not needed for demo.





Security



None native. TLS tunnels or network isolation only. Never expose 502 to the browser.

D. Realtime architecture

Simulator / PLC
   OPC UA subscription  ──►  Connector service
   Modbus poll (250–500 ms) ─┘
                              │
                              ▼
                     Runtime cache (memory or Redis)
                              │
                              ├─ WebSocket fan-out → HMI
                              └─ persist last-value + quality + ts

OPC UA subscriptions are the preferred plant-side mechanism. Modbus is polled. The browser never sees either protocol.
